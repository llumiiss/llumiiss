## Hi, I'm Maksym 👋

Computer Science student at the **University of Silesia** (Katowice, Poland), building full-stack web apps and native Android. In my spare time I do 3D modeling ([Sketchfab](https://sketchfab.com/llumiiss)).

I like projects that solve a real problem from start to finish: I design the database, write the API and UI, add tests, and document it so someone else can run it in five minutes.
